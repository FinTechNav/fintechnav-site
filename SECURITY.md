# Security policy

Security fixes apply to the current `main` branch and the production deployment built from it.

Please report vulnerabilities through this repository's private vulnerability reporting feature when available, or email **brad@fintechnav.com**. Include affected URLs or files, reproduction steps, and the potential impact. Do not include passwords, brokerage tokens, personal financial data, or usable API keys.

Avoid public issues containing exploit details or credentials. Do not test by sending trades, payments, unsolicited emails, or destructive requests against the live site.

Dependency changes are reviewed through pull requests, with security tests and an npm advisory check. Automated dependency updates do not merge themselves.
