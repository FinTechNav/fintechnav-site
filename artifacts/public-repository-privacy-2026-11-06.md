Both public journals contain engineering-only notes; the full previous versions remain in ignored local storage.

## History and provider remediation

The initial current-tree Gitleaks scan found zero credentials. A separate complete local-history scan found seven potential leaks in retired payment/demo/test files. GitHub also has an open historical Google API key alert. Removed screenshots and raw journals remain recoverable from older commits and public archive tags until those refs are cleaned.

A full pre-cleanup Git bundle was verified and retained only in ignored local storage. Any history replacement must be prepared and scanned in isolation, then explicitly coordinated with protected-main requirements. A normal PR merge cannot remove its own sensitive ancestors. Keep protections in place until the owner approves a concrete rewrite and recovery plan.

Removing historical values does not revoke them or erase copies in forks, clones, cached commit pages or pull-request refs. Verify/revoke affected provider credentials, and request GitHub Support cache/ref removal where needed. The historical secret alert must stay open until remediation is verified. Do not publish credential values in support requests, PRs or logs.
