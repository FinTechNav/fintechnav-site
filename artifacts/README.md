# Workspace artifacts

Commit reviewed engineering reports, configuration snapshots and public session notes here. Keep their names and dates explicit; deployment output excludes this directory.

Personal research, account information, raw screenshots, support correspondence, supplied inputs, generated SBOMs, layout fixtures, PR drafts and recovery bundles belong in **`artifacts/local/`**, which is gitignored. Do not force-add it. Local archives are recoverable copies, not part of GitHub or Netlify deployment.

The November 6 cleanup preserves historical raw logs and retired source in that local archive. Public session logs retain the recent engineering history and rationale. Removing files from the current branch does not erase older Git history.

See [INDEX.md](INDEX.md) for the public engineering catalog. Private research catalogs should stay inside `local/`.
